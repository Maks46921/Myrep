# Глоссарий перевода PolitGame (русский -> английский)

Обязательные переводы (ключи данных, код сравнивает их как строки):
- Группы интересов: Рабочие = Workers, Бизнес = Business, Пенсионеры = Pensioners, Молодёжь = Youth, Бюджетники = Public sector,
  Село = Rural, Силовики = Security forces, Экологи = Environmentalists (в любой строке, где это название группы).
- «(вы)» после имени лидера = «(you)». «Ваша партия — » в начале описания = «Your party: ».
- «Военный счёт» = «War score» (в начале строки).
- Черты партий: прагматик = pragmatist, идеолог = ideologue, лояльный = loyal, оппортунист = opportunist.

Стиль:
- Британский/международный английский нейтрального тона, как в стратегической игре (Paradox-like). Коротко и ясно.
- Деньги: «12,5 млрд €» -> «€12.5 billion», «млн» -> million, «тыс.» -> thousand; десятичная запятая -> точка. «% ВВП» -> «% of GDP».
  «п.п.» -> «pp». «капитал -2» (политический капитал) -> «capital -2».
- Партии: официальное английское название, если есть, иначе перевод смысла; аббревиатуры латиницей в оригинальной форме
  (СДПГ -> SPD, ХДС -> CDU, АдГ -> AfD, ВМРО-ДПМНЕ -> VMRO-DPMNE, СНСД -> SNSD). Имена людей — общепринятое английское написание
  (Христиан Мицкоский -> Hristijan Mickoski, Борьяна Кришто -> Borjana Krišto).
- Названия стран, регионов, городов — английские экзонимы (Северная Рейн-Вестфалия -> North Rhine-Westphalia, Скопье -> Skopje).
- Кавычки «ёлочки» -> обычные “ ” или ' (не ASCII-двойные кавычки " — можно, но лучше “ ”).
- Обрывки фраз и падежные формы (премьер-министру, региона, депутатов) -> нужная английская форма без падежа (prime minister, region, MPs).
- Должности: канцлер = chancellor, премьер-министр = prime minister, Собрание/Сейм/Скупщина — оригинальное название органа (Assembly, Saeima, Sejm, Skupština).

Symphony (v39_1–v53_1), обязательные формы:
- Игра называется Symphony (не PolitGame).
- Организации: ЕС = EU, НАТО = NATO, ООН = UN, ОДКБ = CSTO, ЕАЭС = EAEU, СНГ = CIS, ОБСЕ = OSCE, Совет Европы = Council of Europe,
  ОЭСР = OECD, Еврокомиссия = European Commission, еврозона = eurozone, Шенген = Schengen, ЕЦБ = ECB, МВФ = IMF, СБ ООН = UN Security Council.
  «фонды ЕС» = «EU funds», «Саммит ЕС» = «EU summit» (код ищет эти слова в тексте событий).
- Рамки интерфейса: Бюджет = Budget, Экономика = Economy, Политика = Politics, Карта = Map, Организации = Organizations.
- Экономические модели: Рыночная экономика = Market economy (начинать с Market), Социальная рыночная... = Social market... (начинать с Social),
  Государственный капитализм = State capitalism.
- Технологии: «ур.» (уровень) = «lvl»; «нужен предыдущий уровень» = «needs the previous level».
- Строки, начинающиеся с «нужно …», переводить начиная с «needs …»; начинающиеся с «риск» — начиная с «risk».
