# PolitGame

Политико-экономическая игра-симулятор на Godot 4.3 (GDScript). 34 европейские страны, время по дням (экономика — по неделям и месяцам), коалиции, выборы, законы,
экономика, регионы, дипломатия, население из агентов.

## Запуск
1. Откройте Godot 4.3 → **Import** → выберите `project.godot` из этой папки → **F5**.
2. Игра стартует с выбора страны. Для тестов страна задаётся аргументом `country=XX`.

## Устройство
- `main.gd` — вершина цепочки скриптов (запуск, выбор страны, ввод). Остальная игра — модули `scripts/**`,
  каждый `extends` предыдущий (порядок в `scripts/CHAIN.txt`). Подробная карта: `docs/MAP.md`.
- `scripts/data/` — таблицы данных (только `const`): справочники, события и законы, пакеты стран.
- `scripts/state/` — переменные состояния игры.
- `scripts/logic/` — механика: политика, законы, экономика, регионы, выборы, коалиция, события, ход, мир, радикальные законы, агенты, автопилот, журнал.
- `scripts/ui/` — окна и экраны.
- `scripts/classes/` — отдельные классы (плавающее окно, полукруг парламента, агенты и др.).
- `tests/` — тесты (Godot headless), `tests/golden/` — эталоны поведения.
- `tools/` — инструменты разработки, `docs/` — правила, спецификации, карта.

## Разработка
```
tools/test.py quick        # быстрая проверка (~1 мин)
tools/test.py full         # все тесты × 34 страны
tools/test.py agents -c DE # один тест, одна страна
python3 tools/stubs.py     # после добавления функции, которую зовут «снизу вверх»
python3 tools/mapdoc.py    # обновить docs/MAP.md
tools/shot.sh FR 6 14      # скриншот вкладки (страна, экран, месяцев игры)
python3 tools/styles.py -j 4 # стили игры × партии × страны × 30 лет (долго)
python3 tools/gen_ate.py   # пересобрать АТЕ (data/ate.dat) после правки границ регионов
python3 tools/gen_fleet.py # пересобрать морские районы и порты (data/fleet.dat)
```
Фиксированный seed для воспроизводимых прогонов: аргумент `seed=N`.
Правила проекта и чек-лист новой страны: `docs/RULES.md`.
