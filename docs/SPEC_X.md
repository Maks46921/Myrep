1. **Законы** — не менее 8 новых тем, из них **не менее 3 «больших» национальных реформ** (конституционных/системных, `fund=True`, дорогих 35–50 политкапитала, с сильными эффектами и разной реакцией партий), основанных на реальной повестке страны (примеры: Франция — Шестая республика/пропорциональные выборы/реформа 49.3, пенсионная система «по очкам»; Нидерланды — выход из ЕС/референдумы, азот; Бельгия — конфедерализация/раскол страны, объединение Брюсселя; Люксембург — ... ; Швейцария — вступление в ЕС/ЕЭП, нейтралитет, обязательные референдумы; Австрия — нейтралитет/НАТО, фёдеральный раздел; Польша — судебная реформа, отделение церкви, ЕС/евро; Чехия — евро, референдум о выходе из ЕС/НАТО; Дания — оборонная оговорка, Гренландия; Норвегия — вход в ЕС, нефтяной фонд; Швеция — НАТО-ядерное оружие, пенсионная/шведская модель; Италия — премьератто (прямые выборы премьера), автономия регионов, мост через Мессину; Испания — амнистия/референдум в Каталонии, федерализация, монархия; Португалия — регионализация, золотые визы, пенсии). Остальные — обычные реформы: налоги, здравоохранение, образование, армия, миграция, жильё, энергетика, язык, судебная система, сельское хозяйство, культура, транспорт и пр. Не дублируй темы, уже существующие в базовом `l_<cc>.py`/`laws_c.py` для этой страны (проверь `topics(...)`), и **НЕ используй зарезервированные id**: gov_form, econ_model, civil_rights, trade_policy, social_model, property_rights, military_state, debt_default, state_church, eu_policy, state_structure (их движок расширяет сам радикальными вариантами: монархия/диктатура/плановая экономика/автаркия/выход из ЕС и т.д.).
   Формат V/T — как в `laws13.py` (вариант 0 — действующий порядок без эффектов; остальные: `c` (15–50), `s` {группа: −4…+4}, `a` (growth_bonus, equal_shift, extra_spend, sec_bonus, mood_shift, dem_shift, dip_bonus, capital_bonus, reg_unrest_shift, auto_shift, eff_bonus, corr_shift, unemp_base, cb_bias, reg_dev_bonus), `st` (env_lvl, edu_lvl, health_lvl, infra_lvl, security_lvl, corruption, equality), `rg`, `set` (constr, impeach_seats, threshold, parl_term…), `debt`, `ps` (по архетипам партий СТРАНЫ: own soc lib left green popl popr cons euro region prot oth; −10…+10; отражай реальные позиции партий!), `tag` (dim, ±1)). 3–5 вариантов на тему. Тексты — по-русски, живо и конкретно, с реальными реалиями; последствия сбалансированы (не должно быть «очевидно лучшего»).
2. **События** — не менее **15** новых (`EVENTS_X`), специфичных для страны, формат как в SPEC_NEW.md §3: {"t","o":[{"l","fx"}…2–4],"cond"?,"reg"?}. Допустимые fx-ключи: slider, support, capital, shock, debt, unemp, infl, all, state, regall, reg, reg_transfer, econ, dip, other_rev, sector. Не менее 3 с `reg` (региональные; в тексте «{r}»), не менее 3 с `dip` ({код_страны: ±1…6}; коды: DE FR NL BE LU CH AT PL CZ DK NO SE IT ES PT), 4+ «больших» драматичных (скандал, катастрофа, всеобщая забастовка, кризис коалиции, референдум, теракт, пандемия/энергокризис, миграционный кризис, спор с соседом, крах банка, мятеж армии и т.п.), включая 1–2 события, где вариант «жёсткие меры/превышение полномочий» даёт силу, но бьёт по демократии (`state`/`all`/`support` — без новых ключей), а мягкий — наоборот. Подписи вариантов — конкретные действия, цена в скобках.
3. **Новости** — не менее **8** (`NEWS_X`): {"text","fx"} (мелочи: support, shock ±0.3, all ±2, state).
