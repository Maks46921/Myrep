# Балансные прогоны (v28)

Стенд: `python3 tools/bal.py [-c DE,FR] [-p idle,open,closed,secular,trade_war,deals,aid,mix] [-m 84] [-j 2]`
(скрипт `tests/bal.gd`; при каждом ходе политкапитал пополняется до 60, чтобы проверить крайние стратегии; итог — `.testlogs/bal.json`).
Опции: все события включены (`socev=1 exev=1 fedev=1`).

## Что нашли в v27 и как исправили
| Находка (84 мес., DE/FR/LU/PL/NO/ES) | Исправление в v28 |
|---|---|
| Соглашения со всеми партнёрами: ВВП +36…55% (idle +17%) | коэффициент 1,5 → 0,4, убывающая отдача по ступеням (1; 1,7; 2,2): итог ≈ +3…8% |
| Торговая война со всеми: безработица 13–18%, инфляция 10%, ВВП −12…−18% | пошлины 0,5 и ответ 0,8 с отдачей (1; 1,8; 2,6): итог безработица 8–14%, ВВП −11…+5% (малые открытые страны страдают сильнее) |
| Открытые границы в Люксембурге: население +26%, напряжённость 94, интеграция 0 | приток ограничен ≈22‰ в год (или 1,2× стартового), ступени 0,25/0,65/1/1,45/1,9; штраф интеграции ограничен; итог +5%, напряжённость 3–13 |
| Закрытые границы: эмиграция −9% населения (LU) | «отток» частично возвратный: падает вместе с притоком; итог −7% только для страны с огромной долей иностранцев |
| Покупка долга партнёров: у малых стран долг ×7 за 3 мес. | одна ступень ≤ 1,5% ВВП своей страны |
| Эффекты конфессий опирались на стереотипы (рост, налоги) | упрощены до механизмов: сплочённость общин, рождаемость, возрастная структура, налоговая мораль; разница между конфессиями малая |
| Вера агентов не менялась при миграции/секуляризации | раз в 3 мес. агенты подтягиваются к модели (регион × конфессия) |

## Что осталось как есть
- Франция при полном бездействии (idle) приходит к долгу 150% ВВП примерно за 56 месяцев — это поведение базовой игры (воспроизводится и со всеми опциями v27 выключенными).
- Массовые «помощь + выкуп долга» всем партнёрам каждые полгода разоряют страну за 3–4 года: это плата за влияние, ограничена политкапиталом.
- Секуляризм: +2,6…5,3 п.п. нерелигиозных за 7 лет при максимальном курсе — правдоподобно для Европы.
