# Как писать данные новой страны (v30: Великобритания GB, Ирландия IE)

Формат и смысл всех полей — в `docs/SPEC_NEW.md` (старое ТЗ, раздел 2–4: партии, макро, регионы, законы, события, баланс).
Старый конвейер (`w13/*.py`, `check.py`, `calib14.py`) больше НЕ работает: данные пишутся сразу в формате итоговых файлов `data/countries/XX.dat`.
Образцы формата: `data/countries/NO.dat` (8 регионов), `NL.dat` (12 регионов), `LU.dat` — читать так:

```python
import sys; sys.path.insert(0, "tools"); import datio
d = datio.loadn("data/countries/NO.dat")      # обычный Python-словарь, целые ключи — int
```

## Что сдать
Модуль `tools/newc/data_<cc>.py` (можно разбить на части `gb_laws.py`, `gb_events.py` и т.п. — импортируйте их из главного модуля).
Сейчас там **заготовка** (копия NL/NO с кодами регионов страны) — её надо заменить настоящим содержимым. Модуль обязан определить:

| имя | что |
|---|---|
| `D` | словарь страны: ровно те же 50 ключей, что в `NO.dat`, кроме `DIP_ORDER`, `DIP_C`, `DIP_LIKES` (их строит сборщик). Структура каждого ключа — как в NO.dat. |
| `E` | список из N строк по 10 чисел: РЕАЛЬНЫЕ результаты последних выборов по регионам (слоты партий 0..9); N = число регионов в `D["REGIONS"]` в том же порядке |
| `WORLD` | словарь мировой записи: name, cap, latlon (lat, lon столицы), pop, gdp, debt, growth, infl, unemp, def (дефицит % ВВП, профицит <0), stab, appr, gov, gov_party, pot, ecb_w, stance{eu,aus,trd,brd,nuk}, desc, leader, pn (10 коротких названий партий для мировой карты), eu, euro, likes, dislikes (тексты «что нравится/раздражает партнёров»), open, stance0, ccol (r,g,b,1), rel{код: 0–100 — отношения с каждой из ДРУГИХ 16 стран игры}, trade_x{код: экспорт страны в ту страну, млрд €/год, товары+услуги}, trade_m{код: импорт из той страны} |
| `REG_EVENTS` | ≥ 8 региональных событий (формат — `REG_EVENTS_CC["NO"]` в `scripts/data/data_core.gd`; регионы адресуются как `"reg": "code:SCO|WAL"`) |
| `ELEC` | запись для `ELEC_DATA` (формат — там же, раздел «Выборы» в SPEC_NEW.md §5) |
| `RAD_CUR` | строка «Конституционная монархия» и т.п.;  `MONARCHY` — True/False |

Остальные 15 стран: DE FR NL BE LU AT CH CZ DK ES IT NO PL PT SE + вторая новая страна (GB↔IE). Коды регионов ЗАДАНЫ картой и менять их нельзя:
GB: SCO WAL NIR NEE NWE YOR EMI WMI EOE LON SEE SWE (12), IE: BOR WES MLD MWE MEA DUB SEA SWT (8).

## Объём и качество
Как у готовых стран (см. NO/LU/PT): ≥ 36 тем законов (`DE_TOPICS`, общие темы fiscal_rule/eu_policy/citizenship_law/rent_control/schengen/state_structure/impeach_rule/referendum_law/energy_policy + 25 и более уникальных по теме страны), ≥ 45 событий (`EVENTS_C`: ≥ 5 с `reg`, ≥ 8 с `dip`), ≥ 24 новости, `LAW_TAGS` для тем с внешнеполитическим смыслом, `PARTY_LAW_DEMAND`, `MIN_SPECIAL`, `PARTY_MINISTRIES`, `PARTY_DEMANDS` (требования партий по ползункам бюджета). Всё на русском, факты — реальные на начало 2026 (можно искать в сети, `WebSearch` режим standard).
Начало игры — январь 2026: партия игрока — партия власти (GB: Лейбористская партия, Кир Стармер; IE: Фианна Фойл, Майкл Мартин, Таосич). Стартовая коалиция должна проходить `gov_ok`, пассивные 60 месяцев не должны приводить к концу игры.
`ps` в вариантах законов — реакции 10 слотов партий (ключи 0..9, значения −10…+10), смысл `c/s/a/st/rg/set/tag` — SPEC_NEW.md §3.

## Проверка и запуск
1. `python3 tools/newc/validate.py gb` (из корня проекта или копии) — формат, суммы, коды регионов. Должно быть «OK».
2. Игровой прогон — ТОЛЬКО в своей копии проекта:
   ```
   cp -r /home/claude/pg /home/claude/work_GB && cd /home/claude/work_GB
   python3 tools/newc/build.py --root /home/claude/work_GB gb      # встраивает страну (только свою) в копию
   python3 tools/stubs.py                                         # (если менялись функции — нет, данные не требуют)
   python3 tools/test.py load smoke start -c GB                    # загрузка, дымовой тест, 60 мес. пассивной игры (t_start)
   ```
   Смотри `.testlogs/*GB*.log` — не должно быть SCRIPT ERROR. Макро: рост 0…3 %, инфляция 1…4 %, безработица ≈ стартовой, долг не взрывается, рейтинг не падает ниже 30 раньше чем через год.
   Подгоняй `OTHER0` (прочие доходы: итоговый стартовый дефицит ≈ `MACRO.def_target`), `GROUP_BASE`, `loy`, `cb_off`, `G_POT`, `RATE0` — по примеру остальных стран.
3. Общую папку `/home/claude/pg` НЕ трогать: итоговый модуль скопирует в неё оркестратор.
