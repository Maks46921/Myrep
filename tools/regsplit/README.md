# Деление регионов (0.64)
Скрипты, которыми Украина и 14 стран разбиты на настоящие области. Нужны `numpy` и `shapely`.
- `spec_*.py` — описания: код региона, название, население (тыс.), ВРП на душу, якорные города, доля площади, описание.
- `regsplit.py` — делит клетки АТЕ, переписывает `countries/<CC>.dat`, `ate.dat`, `world_units.dat`, `soc/cult/fed/world.dat` и события в `data_core.gd`; результат кладёт в `tools/regsplit/out/`.
- `ev_fix.py` — точные коды регионов для событий (номера строк до деления).
- `render.py` — картинки для проверки контуров.
Запуск (из этого каталога): `SYM_DATA=<снимок data/ до деления> SYM_DC=<data_core.gd до деления> python3 regsplit.py spec_it spec_a spec_b spec_c spec_d +UA`, затем скопировать `out/*` в репозиторий.
