# Данные стран для v55_1 (культуры, церковь, промышленность, мегапроект)

Каждый файл `tools/cult/c_<буква>.py` — обычный Python-модуль с одним словарём `COUNTRY = {код_страны: {...}}`.
Справочник идентификаторов — `tools/cult/catalog.py` (народы `CULTS`, группы `GROUPS`, товары `GOODS_X`, `GOODS_I`).
Регионы стран (коды, названия, население в млн) — `tools/cult/regions.json` (`{код: {"regions": [[код, название, млн], ...], "parties": [10 названий]}}`).
Данные ориентировочные, по переписям и оценкам 2020-х годов. Текст — по-русски, коротко, нейтрально, без оценок народов.
