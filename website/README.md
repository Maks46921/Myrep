# Сайт Symphony

Статический сайт об игре: описание, механики, список обновлений, скриншоты. Без сервера и сборки, только `index.html` и картинки в `img/`.

Посмотреть локально: открыть `website/index.html` в браузере.

Выложить на GitHub Pages: Settings → Pages → Deploy from a branch → выбрать ветку и папку `/website` (или скопировать содержимое папки в `docs/`).

Скриншоты сняты из игры (Godot 4.3, xvfb) на 1600 px по ширине в формате WebP.
